About

This website was created to demonstrate my work in ITIS3135 - Front-End Web Application Development at the University of North Carolina at Charlotte. The course, taught by Professor D.I. von Briesen, focuses on developing websites and web applications using modern front-end development techniques. Additional information can be found on the instructor's ITIS3135 teaching website.

Throughout this course, I will gain hands-on experience using HTML, CSS, JavaScript, and various development tools. I will create several websites, each with its own purpose and design, while practicing accessibility, validation, responsive layouts, and effective web design principles.

Tools Used in This Course

  • Visual Studio Code (VS Code)
  • Emmet within VS Code
  • SFTP through FileZilla
  • Git through GitHub Desktop and GitHub.com
  • Browser developer tools
  • The Accumulus Validator

Websites and Projects

The following websites and projects demonstrate the different skills and concepts covered in this course. Some are already established, while others will be developed as the course progresses.

  • Personal Home Portfolio: My personal homepage, which introduces me and links to my coursework.
  • Course Website: My ITIS3135 course website, where assignments and projects are organized.
  • Design Firm Website: Lovegren Designs, my fictional web design and development business.
  • Crappy Page: A deliberately poorly designed webpage used to demonstrate common web design mistakes.
  • Whimsical Product Company: A fictional product-based business website inspired by my course mascot.
  • Student and Peer Management Tool: A planned project for organizing and managing information about students or colleagues.
  • Client Project Website: A future website developed to meet the needs of a client.
